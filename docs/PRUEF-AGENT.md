# Prüf-Agent (vierteljährlich)

Zum Benutzen: In Claude Code (Sitzung im Projektordner) schreiben: **„Starte einen Subagenten mit dem Prompt aus `docs/PRUEF-AGENT.md` (Abschnitt ‚Prompt‘).“** Er liest nur, ändert nichts und liefert einen Bericht. Danach die Funde mit Claude in Pakete oder Backlog-Zeilen aufteilen. Rhythmus: alle drei Monate (Januar, April, Juli, Oktober) und vor größeren Veröffentlichungen. Modell: Opus, Effort High.

